  PART 4 — CONNECT DOMAIN TO VERCEL  (DNS Setup)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP A — Add domain in Vercel:
  1. Vercel → Your project → Settings → Domains
  2. Type: sabyroy.com → click Add
  3. Type: www.sabyroy.com → click Add
  4. Vercel will show you DNS records. You need these two:

     TYPE    NAME    VALUE
     ─────────────────────────────────────────────────────
     A       @       76.76.21.21
     CNAME   www     cname.vercel-dns.com
     ─────────────────────────────────────────────────────
     (copy the exact values Vercel shows you — they may differ slightly)

STEP B — Add those records in Namecheap:
  1. Namecheap → sign in → Domain List
  2. Click "Manage" next to sabyroy.com
  3. Click "Advanced DNS" tab
  4. Delete any existing A records and CNAME records (the default ones)
  5. Click "Add New Record":

     First record:
     → Type:    A Record
     → Host:    @
     → Value:   76.76.21.21  (or whatever Vercel showed)
     → TTL:     Automatic

     Second record:
     → Type:    CNAME Record
     → Host:    www
     → Value:   cname.vercel-dns.com
     → TTL:     Automatic

  6. Click the green tick to save each record

STEP C — Wait and verify:
  → DNS changes take 5-30 minutes (sometimes up to 2 hours)
  → Go back to Vercel → Domains → it will show a green tick ✅
  → Open sabyroy.com in your browser — your website appears!

✅ sabyroy.com is now your live website address

  PART 5 — KIT (CONVERTKIT) EMAIL SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to kit.com → Start for free
   Sign up with your email → verify account

2. GET YOUR FORM ID:
   → Grow → Landing Pages & Forms
   → Create a new Form → name it "Website Subscribers"
   → Style it however you like (it won't be shown on site)
   → Save the form
   → Look at the URL: app.kit.com/forms/1234567/edit
                                              ↑
                                         This is your Form ID

3. GET YOUR PUBLIC API KEY:
   → Settings (bottom left) → Developer
   → Under "API Keys" → copy your "API Key" (NOT the secret key)
   The API key looks like: aBcDeFgH12345678

4. ADD BOTH TO YOUR WEBSITE:
   Open sabyroy-website/content.js in any text editor
   Find this section near the bottom:

     email_provider: {
       provider:    "kit",
       api_key:     "",       ← paste your API key between the quotes
       form_id:     "",       ← paste your Form ID between the quotes
       tag_id:      "",       ← optional, leave empty for now
     },

   Example when filled in:
     api_key:  "aBcDeFgH12345678",
     form_id:  "1234567",

5. SAVE THE FILE → GitHub Desktop → commit → push
   Vercel re-deploys automatically in 30 seconds

6. TEST IT:
   Go to sabyroy.com → enter your own email in the hero form → submit
   Go to Kit → Subscribers → you should see your email appear within 1 minute

✅ Every subscriber now flows directly into Kit
